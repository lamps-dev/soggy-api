# Soggy API
*The most lightweight on memory but the largest in file size (cuz it has all of the images from soggy drives)*
The Soggy API is an API to get a random picture of Soggy Cat!!1!1!1!1

Currently you need Python (optionally also uv) to run it.
This is just a pretty silly api, and you have to get the url of the image directly with code from the API cuz theres no good way atleast for me to embed the image properly as the API response directly, and the URL provided downloads the image directly if clicked in the browser.
However, you can add your own soggy images if you want!1!1!1!1!
